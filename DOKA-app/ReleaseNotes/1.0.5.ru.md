- **DOKA для ИИ-агентов.** Claude Code, Cursor и другие ИИ-агенты на этом Mac теперь умеют работать с DOKA: распознать аудио или видео и получить текст, найти расшифровку в библиотеке, запустить анализ по шаблону, прочитать историю диктовки и поправить словарь. Включается в «Общие → Доступ для ИИ-агентов», там же готовая команда для подключения.
- Всё личное закрыто отдельными разрешениями: по умолчанию агент может только распознавать файлы, которые приносит сам. Если разрешения нет, агент скажет, где его включить. Ключи сервисов агент не видит, а менять настройки и включать микрофон не может. Сервер слушает только этот Mac и без токена не отвечает.
- **API для программ в формате OpenAI.** Raycast, «Команды», другое приложение диктовки или скрипт могут отправить DOKA звук и получить текст — в том числе через локальные Whisper и Parakeet. Включается отдельным разрешением на той же странице. Через API ничего не сохраняется: ни в «Библиотеку», ни в «Историю».
