- **DOKA for AI agents.** Claude Code, Cursor and other AI agents on this Mac can now work with DOKA: transcribe audio or video and get the text, find a transcript in the library, run an analysis template, read dictation history and edit the dictionary. Turn it on in General → AI agent access, where you also get a ready connection command.
- Everything personal sits behind its own permission: by default an agent can only transcribe files it brings itself. Without a permission, the agent tells you where to turn it on. Agents never see your service keys and cannot change settings or turn on the microphone. The server listens only on this Mac and does not answer without a token.
- **An OpenAI-style API for apps.** Raycast, Shortcuts, another dictation app or a script can send DOKA audio and get text back — including through the on-device Whisper and Parakeet. Turn it on with its own permission on the same page. Nothing sent through the API is saved: neither to the Library nor to History.
