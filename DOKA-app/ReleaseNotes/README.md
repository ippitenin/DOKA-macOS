# Заметки релизов

`<версия>.ru.md` и `<версия>.en.md` — что нового в версии, Markdown (списки, **жирный**). Обязательны для `scripts/release.sh`: из них собираются блок «What's new / Что нового» на странице релиза и `<description xml:lang>` в ленте автообновления, которую показывает плашка «Что нового» в DOKA (язык — по языку интерфейса). Пишутся для пользователей: что изменилось для них, без внутренних деталей. Последовательность `]]>` недопустима (лента кладёт текст в CDATA).
