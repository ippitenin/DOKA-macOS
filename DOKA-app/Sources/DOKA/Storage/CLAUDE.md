# Хранилища

Библиотека транскрибаций на диске, «Папка данных», аудио истории и срок хранения. Общие правила проекта, команды, гейты и сквозные инварианты — в корневом `CLAUDE.md`, там же карта всех документов; пути вида `Storage/CLAUDE.md` — от `DOKA-app/Sources/DOKA`.

## Библиотека транскрибаций

(Страница «Транскрибация» — `UI/Main/CLAUDE.md`, экран «Библиотека» — `UI/Main/Library/CLAUDE.md`.)

**Библиотека транскрибаций** (бывшие «Недавние») — стор `Storage/TranscriptHistoryStore.swift` (синглтон, имя сохранено) поверх файлового слоя `Storage/TranscriptLibraryFiles.swift`, модели — `Storage/TranscriptLibraryModels.swift`. Раскладка в `AppDataFolder.currentURL/transcripts/` (переезжает с «Папкой данных» без правок `migrateToTarget`): `<id>/meta.json` — запись `FileTranscriptRecord`, **источник правды**; `index.json` — лишь КЭШ списка; `<id>/transcript.json` — `TranscriptBody` (машинный `StoredTranscript` не мутируется + `analyses` + `edits`); `<id>/text.txt` — плоский текст для поиска; `<id>/audio.m4a` — архив звука. Ловушки, каждая — про потерю данных: (1) пропавший/битый индекс ВОССТАНАВЛИВАЕТСЯ сканированием `meta.json` (битый сохраняется как `index.corrupt-*`), а не становится «пустой библиотекой»; sweep трогает только корзину `*.deleting-*`, `*.part` и папки без meta — папки с телами автоматически не удаляются никогда; (2) удаление — сначала rename папки в корзину, потом индекс; (3) у незавершённых записей индекса meta перечитывается на старте (крэш между записью meta и индекса); (4) весь дисковый I/O — одна последовательная очередь (порядок чтения после записи); `exit()` её не ждёт, поэтому `applicationWillTerminate` зовёт `flush()`; удаление = rename в корзину → индекс → `emptyTrash()` отдельным блоком; после переноса «Папки данных» — `freeze()` до перезапуска: стор (`isFrozen`) отклоняет новые транскрибации, удаления, архивацию, переименование и «Стереть всё аудио» (последние два когда-то меняли только память: запись пропускалась, и после перезапуска возвращались старые заголовки и целое аудио) (синхронное создание папки архива иначе воскресило бы стёртую старую папку, и возврат на путь по умолчанию упал бы с `targetNotEmpty`); (5) миграция журнала v1 `transcripts.json` синхронна в `init` (до `prune`/`resumePendingJobs`), идемпотентна по флагу `migratedFromV1`, легаси переименовывается в `transcripts.v1.bak` (удаляется через 14 дней). Лимита 50 больше нет — остаётся только срок хранения. Источник правды анализа — `TranscriptBody.analyses` (анализ Nexara из запроса — первый элемент); `llmOutput` в результат подставляет `makeResult` из анализов, поэтому удалённый анализ не всплывает. Показанная запись — `TranscriptDocument` (`UI/Main/Library/`), фаза контроллера — `.done(recordID:)`: копии результата в фазе нет, вывод (нарезка + словарь для файлов) мемоизирован документом. Запуск — `FileTranscriptionController.start(source:params:target:)` на снимке `FileTranscriptionParams` (все Nexara-гейты — от его `providerID`, маршрут — `SettingsStore.resolveRoute(providerID:)`: удалённый пресет — ошибка, а не тихий уход на встроенный сервис); `jobID` персистится ДО проверки отмены (иначе оплаченная задача теряет id). Архив звука (`Audio/SourceAudioArchiver.swift`, AAC 24 кбит/с 16 кГц mono, у видео только звук; тумблер `saveTranscriptAudio`, по умолчанию ВКЛ) — задача стора, отмена распознавания её не убивает; фиксация `audio.part.m4a` → `audio.m4a` только если meta записи ещё на месте. Ловушка имени: `AVAudioFile` выбирает контейнер ПО РАСШИРЕНИЮ, и при прежнем временном имени `audio.m4a.part` выходил CAF под именем `audio.m4a` — плеер его играл, а `AVURLAsset` (декодер «Повторить» из архива и «Распознать заново» без исходника, загрузка архива на сервер) не открывал: «нет звуковой дорожки». Расширение временного файла — только `.m4a`; архивы прежних версий один раз на старте перепаковывает в M4A без перекодирования `TranscriptHistoryStore.repairLegacyArchives` (`SourceAudioArchiver.remuxCAF` с явным MIME `audio/x-caf`, задачами стора по одной записи). Поиск — `Util/LibrarySearch.swift` (регистр и ё=е, но НЕ `diacriticInsensitive` — он склеил бы «й» и «и») + actor `Storage/TranscriptTextIndex.swift` (ленивые тексты из `text.txt`). События: `finished` (готово/ошибка, которую пользователь ждал; безнадёжные записи на старте — `notify: false`) и `bodyChanged`. Recovery — `resumePendingJobs()` один раз на старте (`AppDelegate`): sync-сироты кастомных сервисов → «прервано перезапуском», builtin старше 12 ч → «результат истёк» без сети, остальные добираются фоновыми Task со стаггером 0.5 с (лимит Nexara 10 rps); credentials ВСЕГДА builtin (незавершённая async-задача — нексаровская, даже если пользователь переключил сервис), результат — только в стор, фаза контроллера остаётся idle. UI — секция «Библиотека» (см. `UI/Main/Library/CLAUDE.md`). Срок хранения — `TranscriptRetention` (`Storage/Retention.swift`; 12/24/48/72 ч, 7/30 дней, всегда). Дефолт — «всегда» через `TranscriptRetention.resolve(stored:)`: ключ пишется только при явном выборе (`didSet`), поэтому его отсутствие = «не выбирал» (прежний дефолт 12 ч был согласован с жизнью результата на сервере, пока журнал был списком «недавних»; у библиотеки смысл другой). Сокращение срока в «Расширенных» подтверждается алертом, если под новый срок попадают записи (удаление безвозвратно, вместе с аудио и анализами); чистка завершённых записей — на старте и в `.onChange`.

## Папка данных

**Папка данных** (UI — «Расширенные», `UI/Main/AdvancedSettingsView.swift`): `Storage/AppDataFolder.swift`: ЕДИНСТВЕННЫЙ источник пути данных для всех сторов (кастомный путь в UserDefaults `dataFolderPath` читается напрямую, без SettingsStore); перенос — copy→switch→delete с откатом, применение ТОЛЬКО через перезапуск (`Util/AppRelaunch.swift`, общий с restart-алертом смены языка). Ловушка путей: `standardizedFileURL`/`resolvingSymlinksInPath` НЕ срезают `/private` у несуществующих путей — сравнение существующего источника с несуществующей целью слепнет, поэтому в `AppDataFolder.canonicalPath` резолвится самый глубокий существующий предок.

## История диктовок: аудио и срок хранения

(Экран «История» — `UI/Main/CLAUDE.md`.)

- **Аудио истории** — `Storage/AudioStore.swift` (синглтон): после распознавания `DictationController` кодирует исходный WAV в AAC/m4a (`audio/<record-id>.m4a` в Application Support/DOKA, ~24 кбит/с) ДО удаления временного WAV — **но только если включён тоггл `SettingsStore.saveAudio` (по умолчанию ВЫКЛ)**; иначе `audioFileName == nil`. `id` записи фиксируется заранее, поэтому имя файла и `audioFileName` гарантированно совпадают. Намеренно **не** `@MainActor` (`@unchecked Sendable`): кодирование — тяжёлая CPU-работа вне главного потока. Жизненный цикл файлов привязан к `HistoryStore`: удаление записи / `clear` / вытеснение за лимит 200 убирают и аудио, а `pruneOrphans` при загрузке подчищает файлы, осиротевшие после крашей между кодированием и сохранением json. URL файла записи — хелпер `TranscriptionRecord.audioURL` (проверяет наличие на диске).
- **Настройки хранения** — карточка «Данные» в разделе «Основные» (`GeneralSectionView`): тоггл `saveAudio`, срок хранения `AudioRetention` (`Storage/Retention.swift`; 1/3/7/14/30 дней / всегда) и кнопка «Стереть всё аудио» (`AudioStore.removeAll()`, с подтверждающим `.alert`, повешенным на карточку — иначе конфликт со вторым `.alert` смены языка на корне формы). Просроченное аудио чистит `HistoryStore.pruneAudio(olderThan:)` — на старте (`AppDelegate`) и при смене срока (`onChange`); удаляются только m4a, тексты записей остаются. В истории плеер и кнопка «Показать в Finder» гейтятся `saveAudio` (выключен или стёрто → аудио в карточках не показывается, кнопка Finder пропадает).

Другие файлы папки: `LipDataFiles`/`LipDataStore` — `Lips/CLAUDE.md`; `SettingsStore`, `HistoryStore`, `StatsStore`, `KeychainHelper`, `LegacyMigration` — архитектура и инварианты в корне (дашборд и `StatsStore` — `UI/Main/CLAUDE.md`).
