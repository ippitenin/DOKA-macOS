# Системный словарь DOKA: общие замены для всех пользователей.
# Строка — «шаблон → замена»; # — комментарий. Совпадение — по целому слову
# без учёта регистра; у кириллического шаблона с латинской заменой правило
# само ловит падежи («в телеграме» → «в Telegram»), поэтому здесь — только
# основная форма каждого написания.
#
# Правила отбора: шаблон не совпадает с обычным русским словом (поэтому НЕТ
# «зум», «хром», «сафари», «виза», «курсор», «лама», «озон», «редис»,
# «блендер», «канва», «асана», «питон», «дока»), и ни одна его ФОРМА тоже:
# проверено орфографией macOS по всем формам — выкинуты «убер» (уберём),
# «раст» (расти), «бинг» (бинго), «тильда» (символ ~), «юнити» (юниты),
# «хероку», «сони» (у Сони); «гугли/гуглю» отсекает сам движок
# (`ReplacementEngine.formExceptions`). Склоняемые заимствования
# («промпт», «коммит») сюда не входят — в какую сторону их писать, решает
# сам пользователь в личном словаре. Новая версия списка (строка version)
# только ДОБАВЛЯЕТ записи в копию пользователя — его правки не трогаются.
#
