# Экраны главного окна

Страница «Транскрибация», дашборд, история, «Сервис», «Расширенные» и онбординг. Общие правила проекта, команды, гейты и сквозные инварианты — в корневом `CLAUDE.md`, там же карта всех документов; пути вида `Storage/CLAUDE.md` — от `DOKA-app/Sources/DOKA`.

Где описаны остальные файлы папки: `AnalysisController`, `AnalysisPanelView`, `AnalysisTemplatesSheet`, `SpeakerSuggestionController` — `Util/CLAUDE.md` (ИИ-анализ); `LipsSectionView` — `Lips/CLAUDE.md`; `DictationCleanupCard`, `DictionarySectionView`, `SystemDictionaryView`, `ReplacementRulesList` — `Text/CLAUDE.md`; `SoundSectionView` — `Audio/CLAUDE.md`; `HotkeysSectionView` — `Managers/CLAUDE.md`; общие правила вёрстки — `UI/CLAUDE.md`.

## Транскрибация файлов

**Транскрибация файлов** (`UI/Main/TranscribeAudioSectionView.swift`, секция `transcribe`, в сайдбаре — в группе «Диктовка») — самостоятельная утилита: загрузка аудио/видеофайла (drag-and-drop через `.onDrop([.fileURL])` или `.fileImporter`) → транскрипция → показ сегментами с тайм-кодами и копирование. **Намеренно изолирована от пайплайна диктовки**: не пишет в `HistoryStore`/`StatsStore`, не вставляет текст (`Paster`) и по умолчанию не применяет `ReplacementEngine`. Исключение — тумблер «Применять словарь замен» (`SettingsStore.applyDictionaryToFiles`, по умолчанию ВЫКЛ; осознанно в `SettingsStore`, а не локально в контроллере: это пользовательская линза над выводом, а не параметр файла): замены накладывает выходной слой `Util/TranscriptOutput.swift` (`prepare` → `applyingDictionary`) на показ, «Скопировать» и «Сохранить как…». В фазе контроллера и в журнале всегда СЫРОЙ результат; результат `prepare` терминальный — его не хранят и не перенарезают (`withDetail` пересобирает текст из `rawSegments`/`words`, замены пропали бы), поэтому выключение тумблера мгновенно возвращает исходник. Свой стор — `TranscriptHistoryStore` (библиотека, см. `Storage/CLAUDE.md`), сторы диктовки не трогает.
- Сетевой слой, гейт Nexara-параметров и async-режим — `Network/CLAUDE.md`; библиотека на диске — `Storage/CLAUDE.md`; анализ ИИ на странице — `Util/CLAUDE.md`; спикеры и правка текста, экран «Библиотека» — `UI/Main/Library/CLAUDE.md`; ловушка `.disabled` у списков-плашек — `UI/CLAUDE.md`.
- **Состояние** — `FileTranscriptionController` (`@MainActor`, автомат idle→picked→transcribing→done/error, отмена через `Task.isCancelled`), **синглтон** (`shared`, `@ObservedObject`): результат и выбранный файл живут до закрытия приложения и переживают пересоздание вью при переключении секций (`MainWindowView` рендерит контент с `.id(section)`). ВСЕ настройки страницы (язык, диаризация, спикеры, роли, анализ) — локальные `@Published` контроллера, в `SettingsStore` НЕ пишутся: они привязаны к конкретному файлу, а не к пользователю. **Один файл за раз** (осознанно, без очереди/параллели): во время распознавания дропзона заблокирована (`controller.isTranscribing`), иначе новый файл через `accept()` отменил бы текущую задачу; прервать — «Отмена» в плашке прогресса. `transcribe()` ветвится: builtin — async-путь (`submitAsync` → персист job_id в журнал → `waitForResult`), кастомные — прежний sync `transcribeRich`; обе ветки пишут итог в `TranscriptHistoryStore`. Готовый результат — запись библиотеки (`.done(recordID:)`) в раскладке `.inline` компонента `TranscriptRecordView`; открыть запись из полосы «Недавние» — значит перейти в библиотеку (`LibraryNavigator.open`), на странице записи больше не восстанавливаются; `hideResult()` скрывает запись со страницы (крестик в её шапке; запись остаётся в библиотеке). Отмена async-задачи = перестать опрашивать: эндпоинта отмены у Nexara нет, сервер задачу дообработает и тарифицирует — запись честно остаётся «Отменена».
- Готовность сервиса на странице мемоизирована (`@State hasKey`, ключ читается `Task.detached` в `.task(id: providerID)`): `isServiceReady` из тела вью читал бы Keychain синхронно на каждой перерисовке — общее правило в корне («Синхронное чтение Keychain»).
- **Результат** — `TranscriptResult` (карточка в UI называется «Транскрибация»): `segments` для показа, `rawSegments` + `words` для локальной перенарезки, `llmOutput`. «Скопировать» этой карточки кладёт в буфер чистый текст (rich-копия — только у карточки «Анализ»), а форматы (чистый текст / с тайм-кодами / SRT / VTT / по спикерам) идут через меню «Сохранить как…» (`NSSavePanel`) — все строятся ЛОКАЛЬНО из сегментов чистым `Util/TranscriptFormatter.swift` (тестопригоден, как `WordCount`), без доп. запросов к API. Тайм-коды: всегда запрашивается `timestamp_granularities[]=word` — в ОБОИХ режимах сервер отдаёт и сегменты, и пословный массив `words` одним запросом (проверено живыми вызовами; diarize к тому же кладёт `speaker` в сегменты). Имена спикеров — `Util/SpeakerName.swift` (`speaker_N` → «Спикер N+1», `unknown_N` → «Неизвестный N», имена ролей — как есть), имена, заданные пользователем, — поверх (см. «Спикеры и правка текста» в `UI/Main/Library/CLAUDE.md`); цвет бэйджа — `SpeakerName.colorIndices`: `speaker_N` по номеру, остальные по порядку первого появления в исходниках, пропуская номера `speaker_N` (НЕ hashValue — он рандомизирован на процесс).
- **Качество диаризации** — под тумблером ряд равноширинных плашек `OptionTile` (`UI/Main/TranscriptionControls.swift` — общий файл контролов страницы и записи библиотеки; видимы при diarize), значения уходят только при diarize и только не-дефолтные: «Спикеры» (Авто/1–10 → `num_speakers`, подсказка серверу — главное лекарство от «вся запись speaker_0»), «Тип записи» (`diarization_setting`: ТОЛЬКО general («Стандартная») и telephonic — третьего значения в доке Nexara нет, не добавлять; для Zoom и звонков с перебиваниями Nexara рекомендует telephonic) и «Роли». Ловушка: SwiftUI `Menu` с кастомным лейблом на macOS схлопывает плашку в текст с шевроном и игнорирует `maxWidth`, поэтому плашка рисуется чистым SwiftUI, а клик ловит растянутый поверх невидимый `NSPopUpButton` (`TilePopUpOverlay`, `isTransparent` — не рисуется, но получает события; копия паттерна `PopUpButton` из SettingsForm).
- **Роли** (`roles`, только с diarize): Выкл / Авто / Свои роли (имена через запятую). Клиентская валидация — чистый `Util/SpeakerRolesParser.swift` (лимиты на число ролей и длину имени, дубли; ошибка блокирует запуск); имена кодируются ТОЛЬКО `JSONEncoder` (экранирование). Лишние говорящие приходят как `unknown_N`.
- **Детализация тайм-кодов** — `TranscriptSegmentSplitter.Config` (пресеты coarse/medium/fine) + enum `TimestampDetail` в том же файле. Нарезка ЛОКАЛЬНАЯ по границам предложений, поэтому смена уровня на готовом результате перенарезает его мгновенно и без нового запроса (`TranscriptResult.withDetail`, всегда от `rawSegments` + `words` с материализацией правок — идемпотентно). Выбор уровня — сессионный `LibraryModel.detail` (не настройка и не параметр запроса: в тело записи уходят только `rawSegments`/`words`, поэтому контроллер строит запрос с `.server`); попап — в шапке карточки «Транскрибация» у записи, в обеих раскладках.

## Дашборд

**Дашборд** (`UI/Main/DashboardSectionView.swift`, секция `dashboard`) — статистика диктовки. Источник данных — `StatsStore` (синглтон, `stats.json` в Application Support/DOKA): lifetime-счётчики (слова, время, сессии) + посуточные бакеты; инкремент в `DictationController` сразу после `history.add`; при первом запуске — одноразовый backfill из истории (флаг `seededFromHistory`), т.к. история капается на 200 записей и lifetime-агрегаты по ней неполны. Чистые вычисления вынесены в `DashboardMetrics` (value-type, тестопригодно). «Скорость речи» и множитель считаются от **активной речи**, а не полной длительности записи: `AudioRecorder` накапливает время, когда уровень микрофона выше порога речи (`speechLevelThreshold`), и отдаёт его как `speechDuration`; `StatsStore` копит `totalSpeechWords`/`totalSpeechDuration`, по которым `DashboardMetrics.speechWPM` считает темп (фолбэк на полную длительность для старых записей без этих данных, чтобы не делить на ноль). `timeSaved` и `speedMultiplier` согласованы — оба от `speechWPM`. Геро-метрики (множитель «в N× быстрее», сэкономленное время) гейтятся тестом скорости печати: пока `SettingsStore.typingSpeedWPM == 0` — вместо них карточка-призыв пройти тест. 30-дневный график «слова в день» — `DailyWordsChart` на `Canvas` (без Swift Charts, как волны рекордера). Тест скорости печати — `TypingTestView` (модальный SwiftUI `.sheet` от дашборда; нужен фокус клавиатуры, поэтому именно `.sheet`, а не borderless `NSPanel`), фразы — `TypingPhrases` (RU/EN по языку интерфейса, без спецсимволов из-за смарт-замен `NSTextField`); измеряет скорость в словах/мин и сохраняет в `typingSpeedWPM`. Единый подсчёт слов и форматтер длительности — `Util/WordCount.swift` (`String.dokaWordCount`, `formatStatDuration`).

## История

**История** (`UI/Main/HistorySectionView.swift`, секция `history`) — журнал распознанных диктовок поверх `HistoryStore`. Запись (`TranscriptionRecord`) кроме базовых полей (`id/text/date/duration/language` — их трогать нельзя, читает бэкфилл `StatsStore`) несёт **опциональные** метаданные новых записей (`speechDuration`, `model`, `provider`, `microphone`, `transcriptionTime`, `audioFileName`); у старых записей они `nil`, UI и метрики деградируют мягко (`decodeIfPresent`).
- Аудио истории и срок хранения — `Storage/CLAUDE.md`; плеер — `Audio/CLAUDE.md`.
- **Карточка, инспектор, мультивыбор** — карточка раскрывается в `HistoryDetailInspector` (метаданные записи + «Показать в Finder»); режим выбора даёт пакетные удаление / экспорт / анализ.
- **Лента карточек** — карточки на `glassSurface(forceMaterial: true)`: Liquid Glass у пачки glassEffect-вью внутри ScrollView (macOS 26) рисует под ними общий серый бэкдроп на весь viewport с резкими углами — в светлой теме это заметная плита, не возвращать. Лента тянется до самой нижней кромки окна (обрезка краем окна, а не «в воздухе»), сверху карточки при прокрутке растворяются градиентной маской высотой `topFade` с таким же top-inset контента (в покое первая карточка под маску не попадает). Ловушка: системный `scrollEdgeEffectStyle(.soft)` здесь не работает — без настоящего safe-area-бара над скроллом эффект не рисуется вовсе, а `safeAreaPadding(.top)` опускает overlay-скроллбар «в воздух». Скроллбар выключен совсем (`scrollIndicators(.never)`; `.hidden` недостаточно — при прокрутке колесом система его всё равно показывает).
- **Экспорт** — `Util/HistoryExport.swift` (чистые функции, тестопригодны): CSV по RFC 4180 (по мотивам VoiceInk; имена колонок машинные — это data-формат, не локализуются) и объединённый плоский текст.
- **Анализ производительности** — модальный `UI/Main/PerformanceAnalysisView.swift` (`.sheet`) по выбранным записям: сводные плитки, System Information (`SystemInfo` через `sysctl`) и разбивка по моделям/провайдерам с метрикой «во сколько раз быстрее реального времени» (= суммарное аудио / суммарное время распознавания). Чистые агрегаты — `PerformanceMetrics` (value-type, как `DashboardMetrics`); «анализируемыми» считаются только записи с `transcriptionTime > 0` и `duration > 0`, старые без latency сюда не попадают.

## Сервис

**Сервис** (`UI/Main/ServiceSectionView.swift`, секция `service`) — выбор активного сервиса, поля адреса/модели (только у кастомных пресетов) и ключ. Ключ попадает в Keychain ТОЛЬКО после успешной проверки живым запросом (`TranscriptionClient.validateKey`); единственное исключение — ошибка `.noFunds`: ключ верный, поэтому сохраняется, но статус показывает предупреждение о балансе.

**Ключ сервиса сохраняется по адресату, снятому ДО сетевой проверки**
  (`ServiceSectionView.KeyDestination`). Проверка идёт секунды, за это время можно
  переключить сервис — и ключ уезжал в аккаунт того сервиса, который оказался выбран
  к моменту ответа, вплоть до затирания ключа встроенного (платного) сервиса.

## Расширенные настройки

**Расширенные настройки** (`UI/Main/AdvancedSettingsView.swift`) — под-страница «Общих»: drill-in через `@State showAdvanced` и контейнер `DrillIn` (сдвиг справа с проявлением, см. `UI/CLAUDE.md`; NavigationStack в проекте не используется), вход — строка `SettingsLinkRow` с шевроном. Переход «сразу в Расширенные» извне (`consumeAdvancedRequest`) — без сдвига. Внутри: «Показывать иконку в Dock» (`showDockIcon` — `NSApp.setActivationPolicy` на лету в didSet + `WindowManager.refocusMain()`, старт читает настройку в `main.swift`), «Открывать окно при запуске» (`openWindowAtLaunch`, по умолчанию вкл), карточка «Эксперименты» (тумблер `lipsExperiment` — показывает раздел «Губы», см. `Lips/CLAUDE.md`), «Папка данных» (`Storage/AppDataFolder.swift`; путь, перенос и ловушка путей — `Storage/CLAUDE.md`). Карточка «Библиотека транскрибаций» — срок хранения (`transcriptRetention`, сокращение подтверждается алертом), «Сохранять аудио файлов», «Уведомлять о готовности», занятое место, «Показать в Finder» и «Стереть всё аудио транскрибаций»; отдельного переноса у библиотеки нет — она живёт в «Папке данных». Cmd+W/Cmd+M работают только благодаря пунктам меню «Окно» в `AppDelegate.installEditMenu` (без пунктов меню такие клавиши в macOS не работают вовсе); `WindowManager.showMain` делает `deminiaturize` — иначе свёрнутое окно не вернуть из меню-бара.

## Онбординг

**Онбординг** — это секция `home` («DOKA») главного окна. Показывается при старте, пока не выданы оба разрешения и не готов сервис (`SettingsStore.isServiceReady`). Третий шаг — выбор сервиса распознавания сеткой из трёх плиток (`ServiceChoice` / `ServiceChoiceTile`, файловый уровень `HomeSectionView.swift`): облачный (поле ключа, прежний блок) и две локальные модели, у которых прямо в шаге стоит `LocalAssetStatusView(asset: .speech(model), name: model.plainTitle)` — скачивание проходится целиком внутри онбординга, без похода в раздел «Сервис». Имена моделей: `LocalModel.plainTitle` («Whisper Large v3 Turbo», без «(Local)») для строки статуса, `shortTitle` («Whisper») для узкой плитки; `title` выводится из `plainTitle` и остаётся прежней строкой — она пишется в историю через `providerTagForHistory`. Пресеты «своего сервиса» отдельной плитки не имеют: они подсвечивают облачный вариант, а клик по уже выбранной облачной плитке гейтится `guard settings.isLocalService` — иначе выбранный пресет молча сменился бы на встроенный сервис. Эмбиент-фон секции — `FloatingWordsView` (всплывающие слова-приветствия на разных языках; намеренно НЕ локализуются — многоязычность и есть смысл).
